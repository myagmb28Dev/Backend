이메일 관리자 승격

이메일 입력 후 승격 버튼만 누르면 됩니다. 승격 호출에서 `ADMIN_STEP_UP_REQUIRED`가 오면 PassKey step-up을 자동 수행한 뒤 승격을 재시도합니다.

준비 중

관리자 탭 전용 세션 확인 중입니다.

흐름: 소셜 로그인(Apple/Google) → 관리자 로그인 → 이메일 인증 필요 시 메일 발송/리다이렉트 → 재로그인 → PassKey 단계 → 관리자 성공

요구 권한: `ROLE_ADMIN_CONSOLE` + `ADMIN_PROMOTE`
